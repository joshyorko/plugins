## Protocol and example references

- [Plugin extensions](https://developers.openai.com/plugins/build/extensions): composer mentions are Desktop-only; extended forms for registered servers require MCP `2026-07-28` or later with MRTR.
- [ChatGPT UI](https://developers.openai.com/plugins/build/chatgpt-ui): use shared MCP Apps bridge methods first, feature-detect ChatGPT-only extensions, and keep tools useful without UI.
- [MCP Extensions specification](https://github.com/openai/mcp-extensions/blob/main/docs/spec.md): current mention capability, `ui/message`, display modes, onboarding, and form wire formats.
- [TypeScript SDK README](https://github.com/openai/mcp-extensions/blob/main/typescript/README.md): `OpenAIExtensions.message.send`, capability initialization, and `requestFormInput` examples. Installed versions are `@openai/mcp-extensions` 0.1.0 and `@modelcontextprotocol/ext-apps` 1.7.5. The UI SDK does not type draft-only `send:false`, so this package uses the supported active/send path after an explicit click.
- [Bits & Bolts](https://github.com/openai/mcp-extensions/tree/main/plugins/bits-and-bolts): its README is the first-party extension showcase and `src/server/forms.ts` demonstrates MRTR and legacy form compatibility. Luna implements the same form wire contract in its existing Rust server; no TypeScript backend was added.

## Required operator acceptance

Connect this package to the already-approved independent private ChatGPT registration and Secure MCP Tunnel profile. In ChatGPT Desktop, test a composer `@Luna Factory` query for an exact run and task; open each global/thread entrypoint; verify inline expansion, message send and repository form response/cancellation; compare app-visible and model-visible revisions; then refresh/reconnect and confirm context and selection persist. The operator must identify and approve that independent registration/profile first. No route remap, new app registration, credential grant, or browser approval was performed by this PR work.

The six local browser screenshots under `ui/test/visual-snapshots/` are labeled simulator fixtures. They are not evidence of actual ChatGPT rendering.
